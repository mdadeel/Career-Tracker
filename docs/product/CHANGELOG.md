# Changelog — CareerTrack Lite

All notable changes to this project will be documented in this file. This project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]
### Added
- Planned: AI-assisted job description parsing.
- Planned: CSV data import/export engine.
- Planned: Interview email notification alerts.

## [1.0.0] - 2026-07-22
### Added
- Complete functional dashboard with responsive layout.
- Application CRUD module with full data isolation checks.
- Search by company/title, filtering by source/status, and sort capabilities.
- Live deployment pipeline configuration (Vercel, Render, Neon).
- Form validation, disabled states, and dynamic status badges.

## [0.2.0] - 2026-07-21
### Added
- User registration, login, and secure logout.
- Password hashing with `bcrypt` (10 rounds).
- JWT token generator and authentication middleware.
- Client routing and route guards.

## [0.1.0] - 2026-07-19
### Added
- Initial system design and architecture specifications.
- Product Requirements Document (PRD), features list, and user stories.
- Database ER diagram and Prisma schema design.
- API endpoint documentation.
- Coding guidelines and workspace memory configuration.
